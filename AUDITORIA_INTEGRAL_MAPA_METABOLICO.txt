VÍA 1: GLUCÓLISIS (Embden-Meyerhof-Parnas)
----------------------------------------------------------------------------------------------------
• Compartimento: Citosol.
• Sustrato inicial: D-Glucosa extracelular / plasmática.
• Producto final: 2 Piruvato (3C).
• Recorrido paso a paso:
  1. Glucosa extracelular ingresa por transportador GLUT-2 en hepatocito (en tejidos periféricos GLUT-4/GLUT-1).
  2. Glucosa ➔ Glucosa-6-Fosfato (G6P) por Hexoquinasa / Glucoquinasa (GK en hepatocito, Km alta,
     no inhibida por G6P). Gasto: 1 ATP.
  3. G6P ⇄ Fructosa-6-Fosfato (F6P) por Fosfoglucosa isomerasa (PGI).
  4. F6P ➔ Fructosa-1,6-Bisfosfato (F1,6BP) por Fosfofructoquinasa-1 (PFK-1). Gasto: 1 ATP.
     Regulación alostérica: activada potentemente por Fructosa-2,6-bisfosfato (F2,6BP) y AMP;
     inhibida por ATP y Citrato.
  5. F1,6BP ⇄ Dihidroxiacetona fosfato (DHAP) + Gliceraldehído-3-fosfato (GAP) por Aldolasa (ALDOA/B).
  6. DHAP ⇄ GAP por Triosa fosfato isomerasa (TPI).
  7. GAP ⇄ 1,3-Bisfosfoglicerato (1,3-BPG) por GAPDH (+ NAD+ + Pi ➔ NADH + H+).
  8. 1,3-BPG ⇄ 3-Fosfoglicerato (3-PG) por Fosfoglicerato quinasa (PGK). Genera: 1 ATP (por triosa).
  9. 3-PG ⇄ 2-Fosfoglicerato (2-PG) por Fosfoglicerato mutasa (PGM).
  10. 2-PG ⇄ Fosfoenolpiruvato (PEP) por Enolasa (- H2O).
  11. PEP ➔ Piruvato por Piruvato quinasa (PK, L en hígado, M1/M2 en músculo). Genera: 1 ATP.
• Diagnóstico para un lector nuevo:
  - Trazabilidad general: EXCELENTE. Las flechas verticales descienden claramente.
  - La bifurcación de la aldolasa en Y hacia DHAP (a la derecha) y GAP (centro) es comprensible.
  - Los metabolitos cuentan con estructura de Fisher o fórmula esquemática y número de carbonos [6C]/[3C].
• Hallazgos menores:
  - El rótulo de GLUT-2 en la membrana plasmática debe recalcarse como específico de hepatocito y
    células beta pancreáticas, para evitar que el alumno lo confunda con el GLUT-4 muscular dependiente
    de insulina.
• Veredicto: VÍA 1 TOTALMENTE COMPRENSIBLE Y BIOQUÍMICAMENTE CORRECTA.

VÍA 2: GLUCONEOGÉNESIS (GNG)
----------------------------------------------------------------------------------------------------
• Compartimento: Compartimentación triple: Matriz mitocondrial ➔ Citosol ➔ Lumen del Retículo Endoplásmico.
• Sustratos iniciales: Piruvato, Lactato, Alanina, Glicerol.
• Producto final: D-Glucosa libre exportada al torrente sanguíneo.
• Recorrido paso a paso:
  1. Bypass 1 (Mitocondria y Citosol):
     - Piruvato entra a la matriz por el MPC (transportador de piruvato mitocondrial).
     - Piruvato Carboxilasa (PC, biotina, dependiente de ATP y activada alostéricamente por Acetil-CoA)
       carboxila a Oxalacetato (OAA).
     - El OAA no cruza la MMI libremente: se reduce a L-Malato por mMDH (consumiendo NADH) o se
       transamina a L-Aspartato por GOT2.
     - Malato sale al citosol vía OGC (SLC25A11) y se reoxida a OAA por cMDH (generando NADH citosólico
       necesario para la reacción de GAPDH en reversa).
     - Fosfoenolpiruvato carboxiquinasa citosólica (PEPCK-C / PCK1) convierte OAA + GTP ➔ PEP + GDP + CO2.
  2. Pasos reversibles glucolíticos en sentido ascendente hasta Fructosa-1,6-Bisfosfato.
  3. Bypass 2 (Citosol):
     - Fructosa-1,6-bisfosfatasa-1 (FBPasa-1) hidroliza F1,6BP + H2O ➔ F6P + Pi (inhibida por F2,6BP y AMP).
  4. F6P ⇄ G6P por Fosfoglucosa isomerasa.
  5. Bypass 3 (Lumen del Retículo Endoplásmico):
     - G6P es transportada al interior del RE por el transportador T1 (SLC37A4).
     - Glucosa-6-Fosfatasa (G6Pasa, subunidad catalítica G6PC anclada a la cara luminal) hidroliza G6P ➔ Glucosa libre + Pi.
     - Glucosa sale al citosol por T2 y se exporta a sangre a través de GLUT-2 (SLC2A2).
• Diagnóstico para un lector nuevo:
  - Trazabilidad: EXCELENTE. La representación gráfica del Retículo Endoplásmico con su transportador
    T1 y la salida de glucosa al torrente sanguíneo es de las mejores vistas en mapas bioquímicos.
• Veredicto: VÍA 2 TOTALMENTE COMPRENSIBLE Y BIOQUÍMICAMENTE PRECISA.

VÍA 3: METABOLISMO DEL GLUCÓGENO (Glucogenogénesis y Glucogenólisis)
----------------------------------------------------------------------------------------------------
• Compartimento: Citosol.
• Sustrato: Glucosa-6-P.
• Recorrido paso a paso:
  - Fosfoglucomutasa interconvierte G6P ⇄ Glucosa-1-P (G1P) mediante intermediario Glucosa-1,6-bisfosfato.
  - Activación: G1P + UTP ➔ UDP-Glucosa + PPi por UDP-Glucosa pirofosforilasa; la pirofosfatasa
    inorgánica hidroliza PPi ➔ 2 Pi desplazando el equilibrio.
  - Glucogenina inicia el cebador; Glucógeno sintasa (GS) alarga enlaces alfa-1,4; Enzima ramificante
    (amilo-alfa-1,4 ➔ alfa-1,6-transglucosidasa) crea ramificaciones cada 8-12 residuos.
  - Glucogenólisis: Glucógeno fosforilasa hidroliza mediante fósforolisis (Pi) liberando G1P (ahorro
    energético: no gasta ATP); Enzima desramificante (actividad transferasa 4:4 y alfa-1,6-glucosidasa)
    libera un residuo de glucosa libre por cada punto de ramificación.
• Diagnóstico para un lector nuevo:
  - Muy claro. El bucle UDP-Glucosa <-> Glucógeno se entiende sin confusión.
• Veredicto: VÍA 3 COHERENTE Y FÁCIL DE SEGUIR.

VÍA 4: VÍA DE LAS PENTOSAS FOSFATO (Shunt del Hexosa Monofosfato)
----------------------------------------------------------------------------------------------------
• Compartimento: Citosol.
• Sustrato inicial: Glucosa-6-Fosfato.
• Productos finales: NADPH (poder reductor para lipogénesis y glutatión) y Ribosa-5-P (síntesis de nucleótidos).
• Recorrido paso a paso:
  - Fase oxidativa irreversible:
    1. G6P ➔ 6-Fosfoglucono-delta-lactona por G6PDH (genera 1º NADPH; paso limitante regulado por NADP+).
    2. Lactonasa hidroliza a 6-Fosfogluconato (+ H2O).
    3. 6-Fosfogluconato DH descarboxila oxidativamente a D-Ribulosa-5-P (genera 2º NADPH y libera CO2).
  - Fase no oxidativa reversible:
    4. Ribulosa-5-P epimerasa ⇄ Xilulosa-5-P (Xu5P); Ribulosa-5-P isomerasa ⇄ Ribosa-5-P (R5P).
    5. Transcetolasa (TKT, cofactor TPP): Xu5P (5C) + R5P (5C) ⇄ Sedoheptulosa-7-P (7C) + GAP (3C).
    6. Transaldolasa (TALDO): S7P (7C) + GAP (3C) ⇄ Fructosa-6-P (6C) + Eritrosa-4-P (4C).
    7. Transcetolasa (2ª reacción): Xu5P (5C) + E4P (4C) ⇄ F6P (6C) + GAP (3C).
• DIAGNÓSTICO PARA UN LECTOR NUEVO — HALLAZGO IMPORTANTE:
  - En la parte inferior de la fase no oxidativa aparece el nodo m_gap_pnt («Gliceraldehído-3-P»,
    x=2840, y=995) con el rótulo «➔ Reingreso a Glucólisis».
  - ANOMALÍA: ¡NO TIENE NINGUNA FLECHA QUE LLEGUE A ÉL NI QUE SALGA DE ÉL A MENOS DE 30 PX!
    El estudiante ve una caja con una estructura molecular aislada flotando debajo de la transaldolasa.
    No se dibuja la flecha que viene de la reacción de transcetolasa/transaldolasa ni la flecha que
    desciende hacia el GAP glucolítico.
• Veredicto: BIOQUÍMICA CORRECTA PERO BLOQUEO VISUAL EN m_gap_pnt QUE DEBE CONECTARSE.

VÍA 5: COMPLEJO PIRUVATO DESHIDROGENASA (PDH) Y LUPA MOLECULAR
----------------------------------------------------------------------------------------------------
• Compartimento: Matriz mitocondrial.
• Reacción global: Piruvato + CoA-SH + NAD+ ➔ Acetil-CoA + CO2 + NADH + H+.
• Estructura del complejo multienzimático (representado en lupa_piruvato_deshidrogenasa):
  - E1: Piruvato deshidrogenasa (descarboxila piruvato con TPP).
  - E2: Dihidrolipoil transacetilasa (brazo oscilante de lipoamida transfiere el grupo acetilo a CoA-SH).
  - E3: Dihidrolipoil deshidrogenasa (reoxida la dihidrolipoamida pasando electrones a FAD y luego a NAD+).
  - Regulación covalente: PDK (quinasa) inactiva por fosforilación (estimulada por NADH, Acetil-CoA, ATP);
    PDP (fosfatasa dependiente de Ca2+ y Mg2+) reactiva por desfosforilación (estimulada por insulina y Ca2+).
• Diagnóstico para un lector nuevo:
  - Magnífico despliegue visual. El ciclo de los 5 cofactores (TPP, Lipoato, CoA, FAD, NAD+) es
    absolutamente modélico para la enseñanza universitaria.
• Veredicto: VÍA 5 SOBRESALIENTE.

VÍA 6: CICLO DE KREBS (Ciclo de los Ácidos Tricarboxílicos / Ácido Cítrico)
----------------------------------------------------------------------------------------------------
• Compartimento: Matriz mitocondrial.
• Recorrido paso a paso:
  1. Citrato sintasa: Oxalacetato (4C) + Acetil-CoA (2C) + H2O ➔ Citrato (6C) + CoA-SH.
  2. Aconitasa: Citrato ⇄ cis-Aconitato ⇄ Isocitrato (centro [4Fe-4S]).
  3. Isocitrato DH (IDH3): Isocitrato + NAD+ ➔ alfa-Cetoglutarato (5C) + CO2 + NADH. Paso limitante.
  4. alfa-Cetoglutarato DH: alfa-KG + CoA-SH + NAD+ ➔ Succinil-CoA (4C) + CO2 + NADH (homólogo a PDH).
  5. Succinil-CoA sintetasa: Succinil-CoA + GDP + Pi ⇄ Succinato + GTP + CoA-SH. Fosforilación a nivel de sustrato.
  6. Succinato DH (Complejo II de la CTE): Succinato + FAD ⇄ Fumarato + FADH2.
  7. Fumarasa: Fumarato + H2O ⇄ L-Malato.
  8. Malato DH (MDH2): L-Malato + NAD+ ⇄ Oxalacetato + NADH (equilibrio desplazado por consumo de OAA).
• Diagnóstico para un lector nuevo:
  - Forma circular clásica inmediatamente reconocible. Cada paso tiene su estequiometría de carbono
    [6C], [5C], [4C] y producción energética (3 NADH, 1 FADH2, 1 GTP).
• Veredicto: VÍA 6 PERFECTA EN TRAZABILIDAD Y RIGOR.

VÍA 7: CADENA DE TRANSPORTE DE ELECTRONES Y ATP SINTASA (CTE / Lupa MMI)
----------------------------------------------------------------------------------------------------
• Compartimento: Membrana Mitocondrial Interna (MMI), Espacio Intermembrana (EIM) y Matriz.
• Arquitectura molecular:
  - Complejo I (NADH:ubiquinona oxidorreductasa): 4 H+ bombeados al EIM por cada NADH oxidado.
  - Complejo II (Succinato DH): oxida FADH2 sin bombeo de protones; transfiere e- a CoQ.
  - Coenzima Q (Ubiquinona / Ubiquinol, pool lipídico móvil en la bicapa de la MMI).
  - Complejo III (Citocromo bc1): Ciclo Q; transfiere e- al Citocromo c periférico bombeando 4 H+.
  - Complejo IV (Citocromo c oxidasa): 4 Cit c reducidos + O2 + 8 H+matriz ➔ 2 H2O + 4 H+bombeados.
  - Complejo V (ATP Sintasa F0F1): Rotor c movido por gradiente electroquímico de protones (fuerza
    protonmotriz Δp ≈ 180 mV); subunidad gamma rota 360° sintetizando 3 ATP por cada vuelta (≈8 H+).
• DIAGNÓSTICO PARA UN LECTOR NUEVO — HALLAZGO MUY GRAVE:

      4. cx_krebs_mdh_cte (NADH de MDH) termina en X=2476.8

VÍA 8: LANZADERA MALATO-ASPARTATO
----------------------------------------------------------------------------------------------------
• Compartimento: Cruce de MMI conectando Citosol y Matriz.
• Mecanismo bioquímico:
  - Citosol: cMDH reduce OAA a Malato consumiendo NADH citosólico de glucólisis.
  - Transportador OGC (SLC25A11): antiporte electroneutro Malato ⇄ alfa-Cetoglutarato.
  - Matriz: mMDH oxida Malato a OAA regenerando NADH matricial (que rinde ≈ 2.5 ATP en Complejo I).
  - GOT2 matricial transamina OAA + Glutamato ➔ L-Aspartato + alfa-KG.
  - Transportador AGC1 / Aralar (SLC25A12): antiporte electrógeno Aspartato citosólico ⇄ Glutamato matricial (+ H+).
  - Citosol: GOT1 transamina Aspartato + alfa-KG ➔ OAA + Glutamato, cerrando el ciclo.
• Diagnóstico para un lector nuevo:
  - EXCELENTE. La lupa dedicada lupa_lanzadera_malato_aspartato muestra con total precisión los dos
    transportadores de la MMI y la regeneración cíclica de intermediarios.

VÍA 9: BETA-OXIDACIÓN Y LANZADERA DE CARNITINA
----------------------------------------------------------------------------------------------------
• Compartimento: Citosol, MME, Espacio Intermembrana, MMI y Matriz mitocondrial.
• Mecanismo:
  - Activación citosólica: Acil-CoA sintetasa (FACS) consume ATP ➔ AMP + PPi (gasto de 2 enlaces de alta energía).
  - Lanzadera de carnitina (lupa_lanzadera_carnitina):
    * CPT-1 en MME: transesterifica Acil-CoA + Carnitina ➔ Acilcarnitina + CoA-SH. Inhibida alostéricamente
      por Malonil-CoA (evita ciclo fútil con lipogénesis).
    * CACT (SLC25A20) en MMI: antiporte Acilcarnitina matriz ⇄ Carnitina libre citosol.
    * CPT-2 en cara matricial de MMI: regenera Acil-CoA matricial + Carnitina libre.
  - Espiral matricial de 4 pasos repetitivos:
    1. Acil-CoA DH (FAD ➔ FADH2, acoplado a ETF y ETF-QO).
    2. Enoil-CoA hidratasa (+ H2O).
    3. L-3-Hidroxiacil-CoA DH (NAD+ ➔ NADH + H+).
    4. Beta-cetotiolasa (+ CoA-SH ➔ Acetil-CoA + Acil-CoA con 2C menos).
• Diagnóstico para un lector nuevo:
  - La lupa de carnitina es de una claridad excepcional. La espiral de Lynen se sigue con total soltura.

VÍA 10: LIPOGÉNESIS DE NOVO (Biosíntesis de Ácidos Grasos)
----------------------------------------------------------------------------------------------------
• Compartimento: Matriz mitocondrial (origen de citrato) y Citosol (síntesis de palmitato).
• Mecanismo:
  - Lanzadera de citrato: exceso de Acetil-CoA se condensa con OAA a Citrato, que cruza la MMI por CIC (SLC25A1).
  - ATP-Citrato liasa (ACLY): Citrato + ATP + CoA-SH ➔ Acetil-CoA + OAA + ADP + Pi.
  - Acetil-CoA carboxilasa (ACC): Acetil-CoA + HCO3- + ATP ➔ Malonil-CoA (3C). Paso limitante activado
    por Citrato e Insulina, inhibido por Palmitoil-CoA y AMPK.

SNIPPET 3: IMPLEMENTACIÓN DE URLSearchParams EN interactividad_html.py
(Permite que ?via=6, ?search=Glucosa y ?state=ayuno funcionen de verdad al abrir el HTML)
----------------------------------------------------------------------------------------------------
```javascript
    // =========================================================================
    // INICIALIZACIÓN CON SOPORTE DE PARÁMETROS URL (?via=X, ?search=Y, ?state=Z)
    // =========================================================================
    function procesarParametrosURL() {
      try {
        const params = new URLSearchParams(window.location.search);
        
        // 1. Resaltar vía específica por número o ID: ?via=6 o ?via=ruta_krebs
        const viaParam = params.get('via');
        if (viaParam) {
          const idNum = parseInt(viaParam, 10);
          if (!isNaN(idNum) && TABLA_VIAS[idNum]) {
            setTimeout(() => highlightPathway(idNum, true), 250);
          } else {
            const entry = Object.values(TABLA_VIAS).find(v => v.grupos.includes(viaParam) || v.nombre.toLowerCase().includes(viaParam.toLowerCase()));
            if (entry) setTimeout(() => highlightPathway(entry.id, true), 250);
          }
        }

        // 2. Ejecutar búsqueda directa: ?search=Glucosa-6-Fosfato
        const searchParam = params.get('search');
        if (searchParam) {
          const input = document.getElementById('ui_search_input');
          if (input) {
            input.value = searchParam;
            setTimeout(() => {
              ejecutarBusqueda();
              if (resultadosBusqueda.length > 0) centrarEnResultado(0);
            }, 300);
          }
        }

        // 3. Activar estado metabólico: ?state=ayuno o ?state=posprandial
        const stateParam = params.get('state');
        if (stateParam) {
          const select = document.getElementById('ui_select_state');
          if (select) {
            select.value = stateParam.toLowerCase();
            setTimeout(() => setMetabolicState(stateParam.toLowerCase()), 200);
          }
        }
      } catch (err) {
        console.warn('No se pudieron parsear los parámetros de URL:', err);
      }
    }

    window.addEventListener('DOMContentLoaded', () => {
      poblarSidebarVias();
      construirIndiceBusqueda();
      fitView();
      procesarParametrosURL();
    });
```
